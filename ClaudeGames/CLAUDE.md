# CLAUDE.md

Ты работаешь в проекте **ClaudeGames** — Telegram Mini App со 106 браузерными
мини-играми + Node.js-сервер + Telegram-бот + админ-панель.

## Прочитай перед работой (именно в этом порядке)

1. **`AGENTS.md`** — полный брифинг: что это, где что лежит, как запустить, твоя
   задача (деплой на сервер), правила.
2. **`docs/HANDOVER.md`** — техническая передача: API-маршруты, схема SQLite,
   логика рекламы, известные нюансы.
3. **`docs/GAME_API.md`** — контракт игры (только если будешь трогать игры).

## Самое важное в двух словах

- Проект **готов и проверен** (106/106 игр прошли смоук-тест). Скорее всего твоя
  задача — **разместить его на сервере**; конкретику даст владелец.
- Запуск: `npm install && npm start` → `http://localhost:3000/` (приложение),
  `/admin` (админка, пароль по умолчанию `admin` — сменить). Игра напрямую:
  `?game=<id>`.
- Работает без токена бота и AdSense (demo-режим); их вписывают позже в админке.
- **HTTPS обязателен** для Telegram Mini App. SQLite (`data/minigames.db`)
  требует постоянного диска. Node.js >= 18.
- Git-ветка: `claude/telegram-minigames-app-uzfypa`, папка `ClaudeGames/` в репо
  `webmysolutions/hitchens`. Что не закоммичено — пропадёт (контейнер эфемерный).
- Не трогай остальное в репозитории `hitchens` (Jekyll-тема). Секреты не коммить.
