# 🎮 ClaudeGames — Telegram Mini Games Platform

Сборник из 106 мини-игр как Telegram Mini App + админ-панель + Telegram-бот.
Оптимизировано для слабых телефонов и медленного интернета (целевая аудитория —
пользователи бюджетных Android-устройств).

## Что внутри

```
ClaudeGames/
├── webapp/          # Мини-приложение (каталог + игры) — чистый JS, без фреймворков
│   ├── index.html   # Оболочка: каталог, поиск, категории, экран игры
│   ├── app.js       # Логика оболочки: i18n, загрузка игр, статистика, реклама
│   ├── mg.js        # SDK игр (canvas, свайпы, счёт, сохранения, хаптика)
│   ├── sw.js        # Service worker: офлайн-кэш после первой загрузки
│   ├── i18n/        # Переводы (ru, en — легко добавить новые JSON-файлом)
│   └── games/       # 106 игр, каждая — один файл game.js, грузится по требованию
├── server/          # Node.js сервер: API, SQLite, Telegram-бот
├── admin/           # Админ-панель (/admin)
└── docs/GAME_API.md # Контракт для добавления новых игр
```

### Оптимизации под слабые телефоны

- Никаких фреймворков: оболочка ~30 КБ, игра грузится только при открытии
- Графика рисуется кодом (canvas/emoji) — ноль картинок и шрифтов
- DPR канваса ограничен (1 на слабых устройствах), детект low-end устройств
- Service worker: после первого захода всё работает офлайн / на 2G
- Пауза игр при сворачивании, отправка статистики пачками через sendBeacon

## Запуск

```bash
cd ClaudeGames
npm install
cp .env.example .env   # заполнить по желанию — работает и без этого
npm start
```

- Приложение: http://localhost:3000/
- Админка: http://localhost:3000/admin/ (пароль по умолчанию `admin` — смените!)

Без токена бота платформа работает в **demo-режиме**: приложение открывается в
браузере, статистика пишется, админка работает. Когда появится токен —
вставьте его в админке (раздел «Бот»), и бот запустится без перезагрузки сервера.

## Подключение к Telegram (когда будет токен)

1. Создайте бота у [@BotFather](https://t.me/BotFather) → получите токен.
2. Задеплойте сервер на любой хостинг с HTTPS (VPS + nginx/caddy, Railway, Fly.io…).
3. В админке → «Бот»: вставьте токен и HTTPS-URL приложения → «Сохранить».
4. В @BotFather включите Mini App: `/newapp` → укажите тот же URL.
5. Бот сам отвечает на `/start` кнопкой «Играть» и ставит кнопку меню.

## Админ-панель

- **Дашборд** — игроки, сессии, DAU, графики за 7/30/90 дней
- **Игры** — вкл/выкл каждой игры, featured, приоритет сортировки
- **Статистика** — по каждой игре: сессии, игроки, средний счёт, топ игроков
- **Баннеры** — своя баннерная реклама: текст/картинка, ссылка, слот
  (каталог сверху/снизу, экран конца игры), вес ротации, показы/клики/CTR
- **AdSense** — client id + слоты; включается тумблером, когда получите аккаунт.
  Свои баннеры имеют приоритет, AdSense заполняет пустые слоты
- **Бот** — токен, URL, приветствия RU/EN, текст кнопки, рассылка по всем игрокам
- **Игроки** — список пользователей с активностью

## API (кратко)

Публичное: `GET /api/games`, `GET /api/config`, `POST /api/track`,
`POST /api/score`, `GET /api/leaderboard/:game`, `GET /api/health`.
Админское: `/api/admin/*` (Bearer-токен после `POST /api/admin/login`).
Подпись Telegram `initData` проверяется HMAC-ом, когда задан токен бота.

## Как добавить игру

1. Создайте `webapp/games/<id>/game.js` по контракту из `docs/GAME_API.md`
2. Добавьте запись в `webapp/games/catalog.json`
3. Готово — игра появится в каталоге и в админке

## Стек

Node.js ≥18, Express, better-sqlite3 (файл `data/minigames.db`), ванильный JS
на фронте. Бот работает через Bot API напрямую (long polling), без SDK.
